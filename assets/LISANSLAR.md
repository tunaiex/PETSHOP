# Model lisansları

Projedeki tüm 3D modeller **CC0 1.0 (kamu malı)** lisanslıdır. Ticari kullanım serbesttir, isim belirtmek zorunlu değildir.

| Klasör / dosya | Kaynak | Lisans |
|---|---|---|
| `models/fish/*.glb` | "3D Fish Pack" – polyy.ai (itch.io) | CC0 1.0 |
| `models/props/akvaryum_dolabi.glb`, `kasa_tezgahi.glb`, `duvar_rafi.glb` | Innerscene Corp (innerscene.com) | CC0 1.0 |
| `models/props/agave.glb`, `egrelti.glb`, `calilik.glb`, `models/decor/*.glb` | tevy.dev | CC0 1.0 |

tevy.dev modelleri, Godot 4.4'ün desteklemediği meshopt sıkıştırmasından arındırılarak (glTF-Transform ile) dönüştürülmüştür.
