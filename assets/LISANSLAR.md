# Model lisansları

Müşteri/çalışan karakterleri **Adobe Mixamo** karakterleridir: Mixamo kullanım koşullarına göre
oyunlarda ücretsiz kullanılabilir (modellerin kendisi tek başına dağıtılamaz/satılamaz).
