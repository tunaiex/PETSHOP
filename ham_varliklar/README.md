# Ham varlıklar (arka plan için modeller ve dokular)

Buraya akvaryum arka planı için indirilen **ham** 3B modeller ve dokular gelir
(kaya, kütük, su bitkisi, kum / çakıl). Claude bunları işleyip oyuna uygun
katmanlara dönüştürür; oyuna giren son dosyalar `CepAkvaryumu_DerinlikV2/` içindedir.

## Nereye yüklemeli?

| Dosya boyutu | Yer | Link |
|---|---|---|
| **25 MB'tan büyük** veya toplam çok büyük (ör. 2 GB) | **Releases** (dosya başına 2 GB'a kadar, repoyu şişirmez) | https://github.com/tunaiex/PETSHOP/releases/new |
| 25 MB'tan küçük tek tük dosyalar | Bu klasör | https://github.com/tunaiex/PETSHOP/upload/ccr-7f768247-c1s1fm/ham_varliklar |

### Releases ile yükleme (telefonda)
1. Tarayıcıda yukarıdaki linki aç (gerekirse "Masaüstü sitesi" modunu aç; GitHub uygulaması sürüm oluşturamıyor).
2. **Choose a tag** → `varliklar-1` yaz → "Create new tag".
3. Başlık: `Ham varlıklar 1`.
4. Alttaki **"Attach binaries"** alanına ZIP / GLB dosyalarını sürükle veya seç.
5. **Publish release**.

## Dikkat
- Repo **herkese açık**: yüklenen her şeyi herkes görebilir ve indirebilir.
- Sadece lisansı uygun dosyalar: **CC0** veya **CC-BY** (CC-BY ise yazar adını not et).
  **NC** (ticari olmayan) lisanslı dosyaları yükleme.
- Boyutu küçültmek için indirirken **2K** doku çözünürlüğü yeterli
  (balık ekranda ~200 px; arka plan 480×480). 4K / 8K gereksiz yere GB'larca tutar.
